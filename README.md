# LUMIÈRE — Веб-приложение парикмахерской (Версия 3)

Красивый сайт и система онлайн-записи студии стиля LUMIÈRE на **Flask** с поддержкой **программы лояльности и кешбэка баллами**:
* **Программа лояльности (Версия 3):**
  * За каждую запись или покупку клиенту начисляется **5% кешбэк бонусами** (1 балл = 1 рубль).
  * Накопленными баллами можно оплачивать до 100% стоимости будущих услуг.
  * Баланс баллов наглядно отображается в личном кабинете в шапке сайта (`💎 X баллов`).
  * В окне записи отображается расчет кешбэка и возможность включить списание баллов со скидкой на итоговую сумму.
* **Разграничение прав (Версия 2):**
  * **Клиенты:** просмотр каталога, запись, накопление и списание баллов.
  * **Администратор (`admin` / `admin`):** эксклюзивные права на добавление новых услуг и удаление позиций.

---

## 💎 Программа лояльности и баллы (Версия 3)

1. **Начисление баллов:** При оформлении визита клиент получает 5% от оплаченной суммы на свой бонусный баланс.
2. **Оплата баллами:** При повторных визитах в окне записи можно отметить галочку «Списать баллы» — итоговая сумма к оплате уменьшится на доступную сумму бонусов!
3. **У тестового клиента `alina_style`** сразу начислено **250 баллов** для проверки списания.

## 🔐 Доступ Администратора (Версия 2)

Для входа с правами администратора:
* **Логин:** `admin`
* **Пароль:** `admin`

После входа под аккаунтом администратора:
1. В шапке появляется статус **«👑 Администратор»**.
2. Разблокируются кнопки **«+ Добавить услугу / товар»** (в баннере) и **«➕ Добавить карточку»** (над каталогом).
3. На каждой карточке услуги появляется кнопка удаления (**🗑**).
4. Обычные пользователи и неавторизованные гости не видят эти кнопки, а бэкенд возвращает `403 Forbidden` при попытке несанкционированного изменения каталога.

## 🚀 Быстрый запуск на локалхосте (Mac / Linux / Windows)

1. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate  # На Windows: venv\Scripts\activate
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите веб-приложение:**
   ```bash
   python app.py
   # или: python main.py
   ```

4. **Откройте в браузере:**
   👉 **http://localhost:5000**

## 🗄️ База данных

Приложение поддерживает два режима работы:

* **Автономный (SQLite, по умолчанию без настроек):**
  Если MySQL не запущен, приложение автоматически использует локальную базу данных `lumiere.db`, в которую сразу загружены все 10 базовых услуг, категории и тестовый клиент. Никаких дополнительных настроек не требуется — сайт сразу работает!

* **MySQL (lumiere_salon):**
  Если у вас установлен и запущен MySQL Workbench:
  1. Выполните дамп `db/lumiere_salon.sql`.
  2. Скопируйте `config.ini.example` в `config.ini`:
     ```bash
     cp config.ini.example config.ini
     ```
  3. Укажите ваш пароль от MySQL в `config.ini`.
  4. При перезапуске сервер автоматически подключится к MySQL.
